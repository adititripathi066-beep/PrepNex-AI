
# PrepNex AI 🚀
### Your Smart AI-Powered Learning & Interview Preparation Platform

PrepNex AI is a modern SaaS landing page concept designed for students and job seekers. It presents a platform that helps users improve their learning journey, track progress, and prepare for interviews.

## ✨ Features

- Modern and responsive landing page
- Clean navigation with working section links
- Hero section with call-to-action buttons
- Features and How It Works sections
- Pricing plans section
- Contact form with input validation
- Success and error messages on form submission
- Mobile-friendly navigation
- Responsive desktop and mobile layouts

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## 📂 Project Structure

```text
PrepNex-AI/
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ How to Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Explore the website and test its interactions.

## 📱 Responsive Design

The website is designed to work on desktop, tablet, and mobile screen sizes.
